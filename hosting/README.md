# Hosting files

Files to upload by hand to the Zenbox account, outside the site build.

- `meblekw.pl/.htaccess` — permanently redirects the old shop at meblekw.pl to https://www.blatydrewniane.eu. Upload to `/domains/meblekw.pl/public_html/`, replacing the old `.htaccess` (keep a copy of the old one to undo).
